# 合规与限流规则

> ⚠️ 平台规则随时变，最终以各平台官方《社区自律公约 / 创作者规则》为准。本文件给"交付前必查"的通用红线与改写安全规则。敏感词库见 `sensitive_words.txt`（非穷尽，须按类目补充）。

## 一、敏感词策略

1. **扫描动作**：交付前对全部生成文字跑 `scripts/sensitive_check.py`，逐词标红 + 给替换建议。
2. **三类词分级处理**：
   - **A 级（硬性违规）**：政治敏感、色情低俗、暴恐、违禁品、赌博引流、诈骗话术 → 一律删除或彻底改写，不可仅替换。
   - **B 级（平台限流）**：绝对化用语（最/第一/国家级/100%有效）、诱导互动（点赞/转发/关注才有）、制造焦虑标题党 → 替换为合规表达。
   - **C 级（类目风险）**：医疗功效（根治/包治/速效）、金融承诺（稳赚/保本/年化）、育儿/教育焦虑 → 加"需资质/需核实"标注或删除。
3. **词库非穷尽**：不同类目（如汽车改装、美妆、保健）风险词完全不同，提醒用户把自身类目的高频风险词加进 `sensitive_words.txt`。

## 二、各平台限流红线清单（通用版，逐条核对）

- [ ] 无标题党（夸大、虚假悬念、"不转不是…"类）
- [ ] 无诱导互动话术（点赞过万更新 / 转发抽奖强引导）
- [ ] 无未声明商业内容（软广/种草须标注"广告/合作"）
- [ ] 无虚假数据/功效宣称（"月入10万""7天瘦20斤"无依据）
- [ ] 无低俗擦边/恶俗审丑/引战骂战
- [ ] 无未授权搬运/去水印盗用他人素材/音乐/肖像
- [ ] 无医疗/金融/功效类违规绝对化用语
- [ ] 无政治、暴恐、违禁品相关内容
- [ ] 无水军式刷量/伪造播放话术
- [ ] 无侵犯隐私（曝他人手机号/地址/聊天记录）

## 三、安全改写规则（去重且不踩线）

1. **结构可学，字句不抄**：借鉴爆款的"钩子→冲突→反转→落点"骨架，台词全部原创重写。
2. **换表达不换事实**：改写不得编造原视频没有的数据/结论；引用须标注来源。
3. **绝对化用语一律降级**：「最省」「第一」→「更省」「性价比高」；「100%有效」→「多数情况下有效」。
4. **诱导词清零**：删除一切"点赞/关注/转发"条件式引导，改为自然行动召唤（"需要清单的评论区扣 1"属中性，可保留）。
5. **风险类目加护栏**：医疗/金融/功效类，结尾加"个人经验，不构成专业建议，请遵官方指引"。
6. **原创声明**：改写版顶部标注「原创改编 · 非搬运 · 已做去重与合规处理」。

## 四、交付前合规闸门（与 SKILL.md 阶段对应）

- 阶段 1–5 全部文字 → 跑 `sensitive_check.py`
- 命中 A 级 → 删除/彻底改写并重扫，直到 0 命中
- 命中 B/C 级 → 替换或加标注，记录到交付清单
- 限流红线 10 条逐条 ✅ 后，才输出最终报告
